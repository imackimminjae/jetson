실행 대상
실제 CUAV Pixhawk의 수정 PX4 SIH 자전거 모델을 사용했다. 별도 Python 차량 모델을 대신 사용한 시험이 아니다.
SYS_HITL=2, MBE_ENABLE=0, 정지·disarmed 확인 후 실행. 기존 lower_tracking_mpc_node 실행파일과 production 설정을 사용했다.
ROS domain91, localhost 통신. 상위 플래너/Isaac 지도 입력은 시험 제어 경로에 포함하지 않았다.
기존 속도6m/s, 하위 가중치와 actuator delay0/tau.05, 차체 기준점1.4m, wheelbase2.8m, 조향환산.35를 유지.
고정 경로는 최초 pose에서 한 번 생성해 지도 좌표로 고정. 이후 좌표와 s를 바꾸지 않고 시각만 갱신하여5Hz 발행.
40m 직선 +40m 좌회전 +20m 직선 +40m 우회전 +40m 직선. 곡선은10m 곡률 증가/20m 일정/10m 감소.
총 경로180m 중 s160m에서 종료, 뒤20m는 하위의 예측거리 확보용이다.

해석과 한계
고정된 매끄러운 경로에서 기존 하위 제어기와 실제SIH가 심한조향진동없이주행했다.
상위 계획의 주기별 변화와 분기 후보 선택을 먼저 조사/수정하는 방향을 지지한다.
하위문제를 완전히 배제하거나 원인을100%상위로확정한 결과는 아니다. 곡선최대37cm편향은남았고RMS오차도0이아니다.
기존주행과 시험경로의 곡률/도로가 다르고, 최종시험의 ROS전송·기록조건도 달라엄밀한동일조건A/B나개선율로해석하면안된다.
앞선 두 중단의 통신/출력갱신 정지 원인은 확정하지못했으며, 비동기전송이그원인을해결했다고단정하지않는다.
원본production설정은수정하지않았다. 시험노드들은종료했고사용자MAVProxy연결은유지했다.

재사용 파일
src/virtual_control/scripts/fixed_path_probe.py: 고정경로발행/감시/기록. 자체arm기능없음.
fixed_path_test_20261001/run_trial.py: SIH상태검증,별도domain에서브리지·하위실행,종료해제확인까지포함.
run_trial.py는실제SIH를움직이는실행기이다. 일반주행제어기·브리지가중지되고 UDP14540/14541이비어있어야실행가능.
활성환경에서재실행하려면ROS환경을불러온뒤고유한 --name을사용한다.
실행예: python3 fixed_path_test_20261001/run_trial.py --name new_trial --curvature 0.06 --no-bag --async-publish
