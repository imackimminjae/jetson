1·4·5·6·7은 최신2026-10-09 기록 중 목표 접근 장면을 사용한다.
2·3은 기존2026-10-08 자료를 사용한다. 2번은 SD-map 참조 경로 그림이며 성공 주행 예시는 미확보.
3번은 기존 목표 접근 주행 장면을 사용한다.

REPORT_SCENARIOS_1_TO_7.pdf: 7페이지 보고용 그림.
figures/scenarios_1to7.png: 전체 개요. figures/scenario1~7.png: 개별 그림.
각 그림에 run ID, 주행 예시의 회차/KST 시각 표시. 원래 번호·출처는 provenance/ 대응표.
tables/: 선택한 목표 접근 예시의 출처 시각. configs/: 해당 주행에 전달한 설정과 경로.

그림 설명: 검은 점선은 SD-map waypoint, 색 실선은 목표 접근까지 실행된 궤적.
시작점은 삼각형, 목표점은 별. 관성 정지 구간은 이 예시 그림의 주행 구간에 포함하지 않는다.
배경은 설계 도로 자료의 재구성이며 차량 외곽 충돌/도로 내 주행 검증으로 사용하지 않는다.
completed는 목표 영역 접근이며 목표 정차 성공이 아니다.
이 자료는 성공 장면을 선택한 소개용 자료이며 전체 시행의 성공률을 제시하는 자료가 아니다.
추가 원인 분석이나 지표 재계산 없이 기존 기록에서 장면을 선택·배치했다.
실행 로그의 원래 시나리오 이름/번호는 바꾸지 않았다.
