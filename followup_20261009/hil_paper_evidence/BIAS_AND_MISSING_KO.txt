편향 자료와 미확보 항목

기존 HIL 편향 검증 결과: 미확보.
최신 30회 및 effective_config가 있는 전체8배치 모두 enable_waypoint_bias=false.
0.17rad는 비활성 파라미터이며 HIL에서 9.74도 편향을 검증했다는 증거가 아니다.
오래된 무명 debug bag 전체가 편향 없는 실험이었다고 단정하는 것도 아니다.
확인 가능한 편향값·실행 설정·의도 출구 라벨·원 도로 truth를 갖춘 cohort를 찾지 못했다.

현재 소스가 제공하는 편향 기능(실험 결과가 아니라 코드 정의)
  p'_i = p_0 + R(theta) (p_i-p_0) + [dx,dy].
  p_0: 원 경로 첫 waypoint, 회전 중심.
  theta: rad, map의 +Z 기준 반시계방향 회전.
  dx/dy: m, map X/Y 방향의 병진.
  순서: 첫 waypoint 중심으로 회전한 후 전역 map 축 병진을 더함.
  인가 위치: upper applyReferencePath 내부 applyConfiguredWaypointBias.
  변환 대상: waypoint 경로. 차량 상태 추정값·occupancy grid를 함께 회전하는 기능이 아님.
  별도 pose offsets, 좌표 초기 정렬은 다른 기능. 경로 편향 실험과 혼동하지 않음.
  /navigation/global_path는 변환 전 입력일 수 있으므로 미래 실험에서
  upper가 실제 소비한 변환 후 waypoint 전체도 별도로 기록해야 함.

기존 로그로 추가 복원 가능한 항목
  - 이미 보존된 원 MCAP의 다른 분기 시점/회차 장면, 추가 속도·오차 구간 통계.
  - B/구간 clipping flag/비용 항 등의 추가 도식. 지금 필요한 기본 신호는 package에 포함.
  - 기존 실패 episode별 자세한 전후 rosout; source CSV가 원 bag으로 연결됨.

추가 계측이 필요한 항목(알고리즘 튜닝과 별개)
  - 실험 화면 캡처와 Jetson·CUAV·연결 케이블 사진; run ID/시각과 연결.
  - Isaac 호스트/OS/버전, scene USD 해시, map metersPerUnit, 카메라 K/TF/ground plane,
    실제 BEV 생성 설정·소스/실행 바이너리 해시.
  - PX4 해당 실행 firmware hash/파라미터 dump, SIH 동역학/차량형상 상수.
  - RGB 취득 stamp, 실제 사용한 TF stamp, grid sequence/생성 stamp,
    upper가 snapshot한 pose/grid sequence를 동일 기준시계로 기록.
  - lower 콜백 진입/종료 steady time, timer 예정 release/실제 진입/발행 완료,
    실패·조기 반환 포함. 측정 자체 오버헤드 별도 기록.
  - 호스트 부하/스케줄링/CPU주파수/열/전력모드. 760ms 사건의 대기 위치를 분리할 계측.
  - SIH ground truth 위치/yaw/차량 모델 내부 조향 상태와 EKF를 함께 기록.
    내부 조향 상태가 있어도 실물 바퀴 센서 측정이라고 부르지 않음.
  - 실물 조향각이 연구 대상이면 실제 센서가 필요. 현재 환경은 명령과 내부 추정치뿐.
  - 독립 road polygon/centerline, 차량 폭·외곽 mesh, simulator contact/collision flag.
    경계 여유는 truth pose에서 변환한 footprint와 polygon 경계 최소거리로 계산하고
    source, 단위, dt, 불확실성, unknown coverage를 함께 보고.

추가 실험이 필요한 항목(이 작업에서 실행하지 않음)
  - 경로 편향: 같은 nominal 시작/목표/의도 출구/도로, 같은 속도·solver·가중치·제약을 고정.
    translation-only와 heading-only를 먼저 분리. 예: map X/Y 각각 ±1/±2m,
    heading ±5/±10도와 0 baseline. 이 값은 제안이며 이미 수행한 조건이 아님.
    각 조건의 초기 상태·B reset 동일, 조건 순서를 바꾸어 반복; 성공만 골라 기록하지 않음.
    비용/soft cap/지도/분기 참조를 바꾸어 편향 성능을 개선하지 않음.
  - 원 waypoint와 변환 후 waypoint, 참 도로/truth pose, 계획·하위 경로·명령을 동시 기록.
    출구 ID의 정답을 미리 고정하고, 출구 성공·차량 중심 도로 내·외곽 도로 내를 각각 판정.
    동일 nominal arclength/교차로까지 거리에서 같은 지도 축척으로 조건을 비교.
    출구를 못 통과하고 정지한 시험은 성공에서 제외하되 도로 이탈과 별도 표기.
  - 목표 정차 성능은 별도 목적/종료 조건/제동 계측으로 검증. 기존 completed를 정차성공으로 전환 금지.
  - 센서/통신 이상에 대한 일반적 복구 성능은 현재 자연 발생 사례만으로 보장하지 않음.
    통제된 장애 주입 HIL 실험이 필요하며 사용자 승인 범위에서 별도로 계획.

운영 적용·추가 주행·계측 노드 실행은 하지 않았다.
상세 미확보 목록은 tables/missing_data.csv, 신호 정의는 sources/signal_dictionary.csv.
