B/soft 코드와 확정 사실
- src/virtual_control/src/tracking_control.cpp의 updateIntervalCentering/intervalTreatment를 읽을 것.
- B는 정상 도로 물리폭의 확정 추정치가 아니라, 참조를 유일하게 포함하고 양 경계가 관측된
  단면 중 최소 길이 후보로 갱신하는 내부 기준폭이다.
- 후보 <=1.5*직전B 이면 B를 교체. 주기마다 상승이 누적될 수 있다.
- 관측 단면 W<=1.5B이면 soft, nominal fallback 문턱은 별도9m.
- soft=0.7이면 양쪽에0.3W씩 빼 최종0.4W, soft=0.8이면 최종0.6W.
  soft라는 이름이지만 축소된 단면은 실제 QP 위치 제약이다.
- soft OFF여도 min(2m,0.45W)의 경계 여유를 양쪽에서 뺀다.
  따라서 아주 좁은 갈래는 soft OFF가 오히려 더 좁을 수도 있다.
- relative_length_factor는 YAML에 있어도 validator가1.5를 고정 요구한다.
- 05:06 B는11.3 ->13.5 ->14.1 ->14.6 ->15.3 ->17.8 ->20.0 ->5.9m.
  원폭20m가8m로 줄어드는 것이 확인됨. 이것만이 늦은 조향의 단독 원인인지는 미확정.
