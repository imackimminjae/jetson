# 2026-10-30 HILS 확정 설정과 S22–S25 주행 기록

하위 MPC는 3-state `[e_y, e_psi, effective steering]`, 1차 응답 시정수 0.74초,
순수 지연 0초를 유지한다. 상위 MIQP의 정수 선택은 모두 DAQP branch-and-bound로
풀며, 선택을 고정한 연속 QP 보정만 허용한다. 전수 탐색으로 되돌아가지 않는다.

S22 출발점은 관측된 도로 중심 쪽으로 2.4m 옮겼다.
`(-250.407, 92.324)` → `(-249.435, 94.518)`이며 나머지 웨이포인트는 같다.
S24는 기존 8개 웨이포인트를 정확히 역순으로 바꿨다. 새 출발점은
`(137.499, -113.874)`, 종점은 `(187.966, 236.679)`이며 출발 방향과 좌표 변환
기준도 남쪽에서 북쪽으로 올라가도록 맞췄다. S23·S25 경로는 같다.

바이어스 0°에서 S22·S23·S24·S25를 각각 3회 주행했다.
**12회 모두 완주했고 모든 회차에서 stationary 정지를 확인했다.**
수정 전 S22의 1회 완주 기록은 이번 12회 묶음에서 제외한다.

## 포함 파일

- 저장소의 `src`와 실행 스크립트: 기록 시점의 소스 스냅샷과 라이선스.
- `drive_logs_20261030_s22_s25`: 원본 MCAP·설정·경로 스냅샷·계획·종료 기록을
  무손실 압축한 32MiB 분할 파일, 파일별 해시, 복구 방법, 직접 열어 볼 수 있는 CSV.
- `diagnostics/long_route_edits_20261030`: 경로 수정 전후와 실제 주행 검증 기록.
- `diagnostics/hils_baseline_confirmed_20261030`: 기본 파라미터 확인과 회귀 테스트.
- `diagnostics/c5_bnb_20261030`: 솔버 비교와 남아 있는 수치·최적해 검증 이슈.

원래 로컬 로그와 작업 저장소는 보존한다. 이전 GitHub 로그 묶음도 유지한다.
이전 브랜치나 기본 브랜치의 이력을 다시 쓰지 않는다.

## 검증과 제한

하위 MPC·조향 응답 회귀 테스트 29개, 경로·출발점 Python 테스트 29개,
좌표 변환 C++ 테스트 5개가 통과했다. 빌드된 실행 파일의 기본 파라미터와
12회 기록의 모델·시정수·BnB 정책을 확인했다. BnB 정수 선택 호출은 10,502회이며
전수 탐색은 0회였다. BnB 수치 실패 41회와 하위 QP 실패 0회를 기록했다.

이 기본값 확정이 모든 MIQP 입력에서 전역 최적해가 같음을 보장하지 않는다.
별도 합성 분기 입력의 최적해 일치 테스트 1개는 여전히 실패한다.
고정 입력 351개 중 7개에서는 BnB의 유효 계획 반환이 실패했다. 해당 실패 기록도
보존했으며 전체 테스트가 통과했다고 주장하지 않는다. 소스 스냅샷에 들어 있는
별도 비교 플래너·실차 기능 전체를 이번 주행으로 검증했다는 뜻도 아니다.

빌드·일반 실행 방법은 [README_HILS.md](README_HILS.md)를 따른다.
`scenario_bias_runtime.json`의 실행 파일 해시는 이번 Jetson 빌드의 지문이므로,
다른 환경에서 재빌드한 파일은 별도로 확인한 후 지문을 갱신해야 한다.

```bash
bash run_scenario_bias.sh 22 23 24 25 --bias 0 --runs 3
```
