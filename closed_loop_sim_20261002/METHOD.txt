독립 폐루프 수치 시뮬레이션 — 시험 설계

목적
기록된 차량 자세를 고정한 재계산을 넘어, 상위 계획 -> 하위 조향 -> 가상 차량 이동
-> 새 차량 좌표의 지도 -> 다음 상위 계획으로 이어지는 폐루프에서 설정 후보를 비교한다.

사용 코드
- 운영 tracking_control.cpp의 경유점 판정, 예측 길이 제한, 이전 계획 재투영,
  기준 경로 생성, 도로 구간 추출, 끝점 목표, MIQP, 경로 보간 함수를 직접 호출한다.
- 운영 lower_tracking_mpc_node.cpp의 QP, 오류 피드백 대체 조향, 출력 필터,
  조향 응답 상태 갱신을 직접 호출한다.
- ROS 타이머와 실행기는 돌리지 않는다. 시험 루프에서 상위 5Hz/하위 10Hz를 호출한다.
- MAVLink는 강제로 비활성화하며 PWM 발행도 비활성화한다. 구동 명령 발행 함수는 호출하지 않는다.
- ROS 초기화가 필요한 생성자를 위해 별도 localhost 전용 도메인 95를 사용한다.

가상 차량
- 비선형 중심점 자전거 모델, 축거 2.8m, 중심점에서 뒤차축까지 1.4m.
- beta=atan(0.5*tan(delta)); 중심점 속도 방향 yaw+beta.
- yaw_rate=v/2.8*cos(beta)*tan(delta).
- 실제 명령 환산은 운영 코드의 0.35rad/정규화 명령을 사용한다.
- 운동 적분 간격 1ms. 조향 1차 응답은 매 간격 정확한 지수 이산화로 갱신한다.
- 속도는 모든 조건에서 0부터 1.5m/s²로 증가해 6m/s를 유지한다.
  스로틀 PI·종방향 동역학·실제 PX4 펌웨어는 이 시험에 포함하지 않는다.
- nominal: 조향 시정수 0.05s, 추가 지연/측정 잡음 없음.
- perturbed: 시정수 0.08s, 추가 지연 20ms, yaw에 진폭 1도 사인 잡음.
  두 조건 모두 하위의 내부 응답 모델 설정은 기존 0.05s/순수 지연 0을 유지한다.

가상 도로
- 직선, 곡선, 곡선+분기+폭 변화의 3종.
- 곡선 경유점은 시나리오3 형태를 회전/이동하고 길이를 1.4배 확대한 인공 도로다.
  자연 3차 스플라인으로 연결한다. 가장 작은 중심선 곡률반경 약 11.8m로,
  실제 제어 한계에서 구현 가능한 회전 범위를 고려했다.
- 곡선 도로 폭은 10m. 폭 변화 도로는 약 7~13m, 추가 분기는 폭 8m다.
- 도로 중심선에서의 거리를 이용한 정적 world 점유 지도(0.1m)를 생성한다.
- 각 상위 주기에 차량 좌표의 128x128, 0.3125m 그리드를 새로 샘플링한다.
  원점 (2.95,-20), 최근 실측 메시지와 동일. 값 0=도로, 100=도로 밖.
- 카메라 오류, 지도 메시지 지연/누락, EKF 위치 점프는 포함하지 않는다.

비교
- 10개 설정 x 3개 도로 x 2개 차량 응답 조건 = 60회.
- baseline, 회전 비용 0.3/0.15/0, 상위 방향 보정 비용 2, 끝점 배율 100,
  경유점 eps 6m, 최소 후보 샘플 4, 하위 조향 변화 비용 80, 약한 출력 필터.
- 각 후보는 기준값에서 명시한 한 항목만 변경한다. 필터만 활성화/속도 제한/alpha를
  묶어서 변경하므로, 이 항목은 명시적인 필터 조합 비교다.
- 길이/시간이 다른 종료 결과를 구분해 저장한다. 후보와 baseline이 모두 도달한
  경로 진행 거리까지의 지표도 별도로 계산한다.
- 조기 종료 때문에 조향 변화가 작아진 결과를 성능 개선으로 해석하지 않는다.

종료와 지표
- 가상 목표 도달: 끝점 4m 이내이며 경로 진행량이 끝에서 3m 이내.
  운영 goal_stop_distance=0.5m의 완전 정지 시험과는 다른 시험 완료 기준이다.
- 경로를 1.5초 이상 갱신하지 못하면 stale_path_stop으로 시험을 종료한다.
  이후 관성 주행/실제 제동 거리는 시뮬레이션하지 않는다.
- 차량 중심이 도로 바깥으로 2m 이상 벗어나면 left_road_stop으로 종료한다.
- 도로 밖 여부는 중심점 기준이며 차량 외곽 충돌 판정은 아니다.
- 목표 도달, 상·하위 실패, 도로 밖 중심점 샘플, 경로 중심선과의 거리,
  조향 포화, 시간당 조향 총변동, 진행량을 정렬한 앞 5m 계획의 변경량을 기록한다.

범위
이 시험은 제어 알고리즘의 가설을 반증/지지하기 위한 인공 폐루프 시험이다.
Isaac Sim의 카메라·도로 생성과 실제 Pixhawk 동작까지 재현한 디지털 트윈은 아니다.
이 결과만으로 실제 차량에 대한 최적값이나 안정성을 확정하지 않는다.
운영 코드와 파라미터는 수정하지 않는다.
