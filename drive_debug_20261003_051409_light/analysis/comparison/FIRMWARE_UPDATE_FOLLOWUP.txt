https://raw.githubusercontent.com/PX4/PX4-Autopilot/94cb2012792b2ae89f0b147cfee53ee31ae550be/src/modules/simulation/simulator_sih/sih.cpp
sensor_step(): dt=(now-_last_run)*1e-6, _last_run=now, read_motors(dt).
read_motors(): _actuator_out_sub.update() 성공 분기 안에서만
_u[i] += dt/_T_TAU * (u_sp-_u[i]) 계산.
즉 필터 갱신 빈도는 새 출력 수신 빈도, 계수의 dt는 매 SIH 루프 간격.
둘의 주기가 다르면 명목 시정수와 벽시계 기준 유효 시정수가 달라진다.
원본에는 Ackermann 타입 자체가 없으므로 최종 패치에서 해당 분기를 사용하는지도 확인 필요.

저장된 mav.parm: IMU_GYRO_RATEMAX=400, SIH_T_TAU=0.05.
이 파일은 현재/각 주행 당시 보드 값을 실시간 검증한 결과로 간주하지 않는다.
400Hz, dt=0.0025 가정 시 갱신 한 번마다 잔차가0.95배.
등가 시정수=-1/(output_Hz*ln(0.95)).
출력30Hz면0.650초,35Hz면0.557초,25Hz면0.780초.
오프라인 계단입력 계산 결과는 original_input_filter_rate_check.json 참조.
실제 최신 actuator_outputs_sim 갱신율이30~35Hz라는 측정 결과는 아니다.
ROS 제어주기10Hz 및 HIL telemetry30Hz를 내부 actuator_outputs_sim 주기와 혼동하지 않는다.

기존 로그의 등가 조향 응답: 어제0.033~0.036초, 오늘0.553~0.736초.

0.5초 watchdog은 0.5초 순수 지연 필터가 아니므로 fitted tau와 직접 동일시하지 않는다.
정지 gate는 설명대로면 at_rest만 제한하므로 조향 필터 변경과 별개로 평가한다.
