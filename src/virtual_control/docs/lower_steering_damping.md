# 작은 오차 변화에 대한 조향 감쇠 조정 (2026-09-24)

03:28:44 녹화(`drive_debug_20260924_032844_light`)에서 제어기는 단일 실행이다.
하위 trace 724개, 약 10 Hz이며 상위 계획 141회는 모두 N=5로 성공했다.
사용자가 soft 변경을 원하지 않는다고 정정하여 시험 중이던 soft 전환 수정은
전부 제거했다. 현재 운영 설정의 차이는 `lower_rd_steering_rate: 8 → 40`뿐이다.

## 판단 근거

03:29:05–07의 직선에서도 횡오차가 약 0→0.06 m로 증가한 뒤 0.5초 경로
갱신 때 거의 0으로 되돌아갔다. 조향은 이에 따라 좌우로 바뀌었다.
이 구간의 작은 반복 보정은 큰 soft 구간 변경 사례와 구분해야 한다.
현재 위치에서 매번 시작하는 참조 경로와 위치·방향 입력의 작은 변화에
하위 제어기가 민감하게 반응하는 양상이므로 조향 변화 비용을 높였다.

조향 변화 비용은 `r_delta * sum((delta[k] - delta[k-1])^2)`이며 첫 항은
직전 실제 적용 명령과의 차이다. 이를 높이면 급한 명령 변화의 비용이 커진다.
추가 통신 지연이나 출력 필터를 가정하는 변경이 아니다. 물리 응답 모델은
지연 0, 시정수 0.05초, 중심점 오프셋 1.4 m, 환산 0.35 rad로 유지한다.

## 녹화 입력 고정 비교

`analysis/compare_lower_damping.py`는 기록된 위치·yaw·속도·경로로 동일한
30스텝 QP를 구성한다. 후보별 직전 명령과 조향 상태는 독립적으로 진행시킨다.
기존 가중치 8에서 기록된 명령과 재계산 명령의 최대 차이는 3.65e-6 rad였다.
4개 후보(8, 20, 40, 80) 모두 705회 QP가 수렴했다.

| 구간/지표 | 기존 8 | 선택 40 |
|---|---:|---:|
| 직선 03:28:55–03:29:15 조향 RMS | 0.488° | 0.340° |
| 같은 구간 조향 총변화량 | 48.45° | 22.25° (54.1% 감소) |
| 같은 구간 최대 절댓값 | 1.553° | 0.874° |
| 커브 03:29:27–45 조향 총변화량 | 295.71° | 239.24° (19.1% 감소) |

총변화량은 연속 명령 차이의 절댓값 합이다. 이것은 **같은 녹화 입력에 대한
명령 비교**이며 새 명령에 따라 차량 위치가 달라지는 실제 재주행 결과가 아니다.
80은 더 강하게 억제하지만 응답 둔화도 커지므로 먼저 40을 선택했다.

## 주행 검증과 적용

실제 C++ 제어기를 사용하는 비선형 중심점 자전거 시험은 가중치 40으로
3/6 m/s, 좌우 S곡선, 실제 시정수 0.03/0.08초, 추가 지연 20 ms를 검사한다.
추가 시험은 0.5초마다 ±3 cm 바뀌는 직선 참조와 약 0.5도 방향 측정 변동을
가진 독립 차량에서 기존 8과 40의 조향 변화량·횡이동을 비교한다.

실행 결과: 관련 CTest 5개 타깃 모두 통과했다. 가중치 40의 비선형 커브
8조건에서 횡오차 RMS는 0.0714–0.0787 m, 초기 오차 0.5 m를 포함한 최대는
0.511 m, 10초 이후 최대는 0.0801 m였다. 기존 8의 같은 시험보다 횡오차는
조금 늘지만 기존 허용 기준을 만족한다.

작은 참조 변동 시험에서는 3 m/s에서 조향 총변화량 2.118→1.111 rad
(47.5% 감소), 6 m/s에서 2.044→1.169 rad (42.8% 감소)였다. 실제 차량
횡이동 RMS도 각각 0.00477→0.00271 m, 0.0121→0.00793 m로 감소했다.
위 수치는 독립 모의 차량 결과이며 Isaac 재주행을 대신하지 않는다.

설정은 다음 정상 실행부터 읽힌다. 이 조정을 위해 별도 제어기 프로세스를
백그라운드로 띄우지 않는다. 실제 흔들림 감소와 커브 지연은 재주행으로 확인한다.
