# SIH 흔들림 완화 및 상위 5스텝 설정 (2026-09-23 22:23 주행)

> 현재 구현은 [실제 진행량 기반 경로 연결과 곡률 입력 제거](progress_based_path_tracking.md)를 따른다. 아래 곡률 상태 입력 관련 설명과 시험 수치는 이전 구현의 기록이다.

## 확인한 현상

`/tmp/sih_repair_mav.tlog`의 22:23–22:24 주행과 ROS 노드 로그를 분석했다.
분석 입력과 재현용 fit 스크립트는 `drive_debug_20260923_2223_analysis/`에 있다.

- 헤딩 검사는 초기 가속 중 약 15° 오차를 검출해 22:23:22.558부터 차단했고,
  정상 범위 복귀 후 2초를 기다려 22:23:26.923에 출력을 재개했다.
- 후반부 EKF−SIH 오차는 약 1–3°인데도 좌우 조향 포화가 반복됐다.
  22:23:13–22:24:23 명령의 약 46.3%가 정규화 조향 절댓값 0.95 이상이었다.
  따라서 전체 흔들림을 헤딩 오류만으로 설명할 수 없다.
- 목표 속도 6 m/s, SIH 실제 최대 속도 약 3.13 m/s. 스로틀 상한은 0.09.
- 이전 하위 곡률열은 0.6 m 간격 경로의 다음 점을 매 0.1초마다 사용했다.
  실제 3 m/s 모델은 같은 시간에 0.3 m만 이동하므로 미래 곡률 진행이 두 배 빨랐다.

## 응답 확인

EKF yawspeed 대신 `HIL_STATE_QUATERNION`의 실제 yaw rate와 속도를 사용했다.
측정 명령을 입력으로 `r_dot=(v/2.8*tan(gain*u_delayed)-r)/tau`를 적합했다.
이것은 SIH의 등가 회전 응답이며 물리 조향각을 직접 측정한 결과는 아니다.

- 적합 구간 22:23:32–22:23:50, 검증 구간 22:23:50–22:24:22.
- 선택 지연 0.30 s, tau 0.997 s, 정규화 조향 gain 0.288 rad.
- 적합 RMS 0.0101 rad/s, 별도 검증 RMS 0.0158 rad/s.
- 즉시 반응/gain 0.30 모델의 RMS는 각각 0.2165/0.2210 rad/s.

지연과 tau는 서로 일부 보상하므로 이것이 유일한 물리 파라미터라고 보지 않는다.
제어 설정은 기존 조향 변환 0.30 rad를 유지하고 delay=0.30 s, tau=1.00 s로 했다.

## 변경

- 상위 `upper_preview_steps=5`, `upper_prediction_dt_sec=0.9`.
  6×0.9=5.4 m/step, floor(34/5.4)−1=5, 총 27 m.
  전방 경계까지 7 m가 남고 기존 한 스텝 reserve를 유지한다.
  장애물이나 유효 도로 구간 부족 시 기존 축소 정책에 따라 5보다 작아질 수 있다.
- 하위 조향 응답 모델 활성화, delay=0.30 s, tau=1.00 s, N=30 (3초).
- `lower_reference_follow_measured_speed=true`를 추가해 원본 s 좌표에서
  `s_nearest+k*v_actual*0.1`의 위치·곡률을 선형 보간한다.
  원본 path/s 메시지는 변경하지 않으며 정지 속도를 인위적으로 올리지 않는다.
  클래스 기본값은 false로 기존 연속 인덱스 동작을 명시적으로 선택할 수 있다.

상·하위 속도 목표 6 m/s, 스로틀 상한, 조향 각도·변화율 제한, 가중치는 유지한다.
과거에 철회한 보상 실험과 달리 이번에는 EKF가 아닌 SIH 실제 응답으로 검증하고,
측정 속도와 곡률 진행의 불일치도 함께 수정한다.

## 검증 범위

수정한 실제 C++ MPC를 독립적인 비선형 yaw-rate 지연 모델에 연결한다.
S자 곡선, 가속, 실제 속도 3/6 m/s, 반응 시간 0.85/1.30 s,
지연 0.20/0.40 s, 조향 이득 ±10%, 약 1°의 헤딩 측정 오차를 포함한다.
실제 Isaac 도로·상위 재계획·EKF 폐루프 재주행을 대체하는 시험은 아니다.

상위 실제 horizon 함수에 34 m/6 m/s/0.9 s/reserve=1을 넣어 N=5를 확인했다.

빌드·설치 완료 (`virtual_control`, exit 0). 설치된 실행 파일을 격리된 도메인에서
실행해 N=30, actuator_model=1, delay=0.30, tau=1.00, backend=disabled를 확인했다.
