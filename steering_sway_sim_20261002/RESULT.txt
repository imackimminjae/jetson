조향 떨림 중심의 가상 시험 — 2026-10-02

목표
분기 선택/도달률보다 반복 조향 떨림 감소를 우선 평가한다.
단, 조향을 느리게 만들어 차량이 경로를 놓치는 결과와 실제 떨림 억제를 구분한다.
운영 상·하위 계산 코드를 호출하는 독립 가상 환경에서 총 186회를 수행했다.
실제 차량 출력은 하지 않았으며 운영 소스와 설정은 변경하지 않았다.

시험 환경
공통: 비선형 중심점 자전거 모델, 축거 2.8m, 뒤차축 거리 1.4m,
상위 5Hz / 하위 10Hz, 1ms 차량 적분, 목표 속도 6m/s.
nominal: 조향 시정수 0.05s, 추가 지연/방향 잡음 없음.
perturbed: 시정수 0.08s, 추가 지연 20ms, 방향에 진폭 1도 사인 잡음.
MAVLink/PWM 출력 없이 localhost 전용 ROS 도메인 95에서 실행했다.

네 종류의 시험
1) fixed_curve: 매 주기 바뀌지 않는 정상 곡선 경로. 하위 자체의 추종 상태를 확인.
2) recorded_front: 실제 18:45:22.898~39.8 앞쪽 기록의 84회 경로와 속도를 재생.
   차량 자세는 기록으로 고정하지 않고 가상 차량이 자유롭게 이동한다.
3) live_curve: 가상 차량 위치에서 지도를 다시 만들고 실제 상위가 경로를 갱신한다.
   차량 이동 -> 지도/계획 변화 -> 조향 -> 차량 이동의 폐루프다. 분기는 없다.
4) injected_sway: 정상 곡선에 알려진 좌우 경로 흔들림을 5Hz로 주입한다.
   offset = 0.7*sin(2*pi*0.35*t) + 0.12*sin(2*pi*1.25*t) [m].
   차량이 따라야 할 정상 중심선을 알고 있으므로 실제 좌우 이동량도 비교할 수 있다.

설정 후보
하위 조향 변화 비용 60/120/180/240/360/480,
방향 비용 0.5/0.3/0.1, 조향 비용 0.3/0.6, 조향 속도 제한 약 1.047/0.7/0.5rad/s,
예측 길이 20/30/40, 출력 LPF alpha 0.9/0.7/0.5/0.3,
공간 진행량을 맞춘 경로 평활화 alpha 0.7/0.5/0.3와 일부 조합을 비교했다.
상위 폐루프에서는 upper_r_dpsi 2/5, 끝점 배율 100, 회전 비용 0.3,
upper_r_dpsi=2 + lower_rd_steering_rate=240 조합도 비교했다.
경로 평활화는 분석용으로 새로 만든 후보이며 운영에 추가한 기능이 아니다.
이 구현은 첫 점은 새 경로에 두고 이후 점들을 이전 경로와 혼합한다.
따라서 이 후보의 실패를 모든 경로 평활화 방식의 실패로 일반화하지 않는다.

평가 기준
- 주 지표: 조향의 0.3Hz 이상 성분 RMS. 보조: 0.7Hz 이상 성분 RMS.
  2차 Butterworth 고역 필터를 양방향으로 적용한 분석값이다. 제어에는 이 필터를 쓰지 않는다.
- 초기 4초와 마지막 0.5초를 제외한다.
- 정상 회전과 떨림의 주파수가 겹칠 수 있으므로 정상 코너링을 완전히 제거한 지표는 아니다.
- 2도 이상 조향 극값 전환, 조향 총변동, 조향 포화, 실제 yaw rate의 고역 성분도 저장한다.
- 원래 평활화 전 계획과의 거리 오차, 정상 곡선 추종 오차, 알려진 도로 중심선과의 거리를 확인한다.
- 기록 입력 시험의 1차 후보 판별에는 각 응답 조건에서 원래 계획 거리 오차 P95가
  baseline+0.10m 이내이고 최대가 baseline+0.20m 이내인지 사용했다.
  이는 비교용 기준이며 실제 차량의 안전 허용오차를 정한 것이 아니다.

핵심 결과 — 두 차량 응답 조건 평균
                                      기준 RMS      변경 RMS     변화
기록 앞쪽 경로 / 하위 변화 비용 240     3.776도       2.685도      -28.9%
흔들림 주입 / 하위 변화 비용 240       5.674도       4.314도      -24.0%
상하위 폐루프 / 상위 2 + 하위 240      1.038도       0.405도      -61.0%

상위 2 + 하위 240 조합의 폐루프 결과
- 0.7Hz 이상 조향 RMS도 0.412 -> 0.114도로 약 72% 감소했다.
- 원래 계획 거리 오차 P95 평균은 0.038 -> 0.036m.
- 두 조건의 최대 오차 평균은 0.133 -> 0.101m.
- 상위 실패 합계 1 -> 0회. 두 조건 모두 목표 구간에 도달했다.
- 현재 회전 비용 0.6과 soft 설정은 그대로다.
- 조향 출력 필터는 꺼진 상태다.
- 서로 다른 두 모델 조건의 결과이며 광범위한 안정성 증명은 아니다.

하위 240 단독의 효과와 부담
- 흔들림 주입에서 정상 도로 중심선 거리 RMS가 0.448 -> 0.350m로 감소했다.
- 고정 정상 곡선에서는 원래 경로 거리 오차 P95가 0.041 -> 0.062m로 조금 증가했다.
  따라서 완전히 공짜인 감쇠는 아니며 정상 곡선 대응의 부담도 존재한다.
- 하위 360/480은 고정 입력 떨림을 더 줄였지만, 상위까지 갱신하는 폐루프에서는
  단조롭게 개선되지 않았고 일부 최대 추종 오차가 늘었다.
- 시험 범위에서 상위 2 + 하위 240 조합을 다음 후보로 잡는 편이 타당하다.

강한 출력 LPF를 우선 선택하지 않는 이유
- alpha=0.3은 조향의 빠른 변화를 크게 줄이는 것처럼 보였다.
- 그러나 흔들림 주입 시험의 정상 중심선 거리 RMS는 0.448 -> 2.691m로 악화됐다.
- 고정 정상 곡선에서도 거리 오차 P95가 0.041 -> 0.407m로 증가했다.
- alpha=0.7/0.5도 기록 경로 입력과 주입 시험에서 떨림이나 추종을 악화시키는 경우가 있었다.
- 따라서 조향 그래프만 조용해진 것을 개선으로 판단하지 않았다.

기록 경로 재생의 중요한 한계
기록된 경로는 원래 차량의 위치를 기준으로 생성됐지만, 이 시험의 차량은 별도로 움직인다.
따라서 시간에 따른 위치가 어긋나면 새로운 경로 시작점과 가상 차량 사이에 앞뒤 거리도 생긴다.
기록 입력 baseline의 원래 경로 거리 P95는 평균 약 3.34m로, 실제 로그의 횡오차와 다르다.
이 값은 실제 주행 재현 오차나 실제 횡오차 예측값으로 사용하면 안 된다.
그 때문에 고정 정상 경로, 알려진 흔들림 주입, 실제 상위가 함께 갱신되는 폐루프를 추가했다.
앞쪽 실제 주행의 심한 진동 원인 전부가 해결됐다는 의미는 아니다.

다음 실제/정밀 지도 시험 후보
upper_planner_node: upper_r_dpsi = 2.0
lower_tracking_mpc_node: lower_rd_steering_rate = 240.0
출력 필터 false, 나머지 현재 설정 유지.
이 값은 가상 시험 후보이며 이번 작업에서 운영 설정에 적용하지 않았다.
