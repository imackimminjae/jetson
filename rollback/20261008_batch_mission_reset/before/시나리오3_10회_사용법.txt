시나리오 3을 10회 시도하는 실행 버튼

실행
1. 기존 px4_ekf_bridge, px4_odom_map_bridge, knu_global_path_publisher,
   upper_planner_node, lower_tracking_mpc_node의 5개 터미널과 별도 bag 기록기를 종료한다.
2. 기존 MAVProxy, PX4 SIH, Isaac/BEV 송신은 켜 둔다.
3. 바탕화면의 “시나리오 3 · 10회 주행”을 실행한다.
   터미널에서는 /home/imac/ros2_ws/run_scenario3_10.sh 를 실행해도 같다.
   기본 10회이며, 터미널에서 --runs 2 등을 붙이면 시도 횟수를 바꿀 수 있다.
   --check 는 기존 노드·포트·저장공간만 점검하며 주행 프로그램을 시작하지 않는다.

동작
- ROS_DOMAIN_ID=1, UDP 수신 14541 / 제어 출력 14540을 사용한다.
- 사용자가 주었던 upper input_timeout_sec=3.0, grid_value_threshold=1도 유지한다.
- ARM, 강제 ARM, 모드 자동 전환, PX4 파라미터 설정은 하지 않는다.
  기존의 사용자 설정 운전 가능 상태가 필요하다.
- 주행 → 회차 결과 기록 → 실제 속도 0.2 m/s 미만 1초 확인 →
  맵 좌표의 출발점/방향 재정렬 → 새 BEV와 참조 경로 수신 → 다음 주행 순서다.
- 맵 좌표 재정렬은 SIH 반복 시험용이다. 실제 차량을 원위치로 옮기는 기능이 아니다.
  Isaac/BEV 쪽은 기존처럼 정렬된 /motive/vehicle/pose 또는 odom_map을 따라야 한다.
- 마지막 10회차도 정지를 확인하고 기록을 닫는다. 실패도 1회 시도로 센다.
- 주행 중 이탈·정체 등은 실패로 기록하고 정지 후 다음 회차를 시도한다.
  60초 안에 정지를 확인하지 못하거나 기록기/저장공간 문제가 있으면 전체 반복을 중단한다.
- Ctrl+C는 주행 허용을 해제하고 정지 확인을 기다린다.
  현재 MAVLink 정지 출력은 중립이므로 즉시 제동이 아니며 관성 주행이 남는다.

판정과 변경 범위
- 상위 비용, 참조 생성/이어받기, B/soft, k=6 및 측면 말단 보호 설정은 그대로다.
- 회차 전환 때 경로와 제어 상태만 초기화한다.
- 배치에서는 상위의 remaining=0 도착 판정을 끄고 기존 배치 판정기를 사용한다.
  completed는 경로 진행률 85% 이상, 남은 경로 12m 이하, 목표와 거리 8m 이하를
  함께 만족한 “목표 영역 접근”이다. 정확한 목표점 정차나 정분기 확정 판정이 아니다.
- 정지 위치와 정지 시 목표 거리(stop_goal_distance_m)는 별도 기록한다.
  따라서 completed라도 관성 때문에 목표를 지나 정지한 경우를 구분할 수 있다.
- 경로에서 15m 이상 이탈 3초, 8m 이상 역진행 3초, 정체 10초,
  진행 없음 30초, 1회 주행 180초 초과 등은 실패로 기록한다.

저장
- /home/imac/ros2_ws/drive_batches/날짜_시나리오3_세션/ 아래에 저장한다.
- bag/: 10회 전체를 MCAP/Zstd 무손실 압축으로 기록한다.
  60초 또는 16 MiB마다 파일이 분할되며, 한 bag으로 연속해서 읽을 수 있다.
- results/하위세션/summary.csv: 회차별 결과·진행률·목표 거리·최종 정지 위치.
- /knu_batch/status의 index/token/phase/stamp로 각 회차와 준비·관성 구간을 구분한다.
- effective_config.yaml: 실제 실행에 전달한 합쳐진 파라미터.
  manifest.json: 기록 항목·실행 파일/설정 해시·공간 기준.
- BEV는 수신되는 모든 프레임을 보존한다. 위치, 실제 하위 참조, 분기 후보,
  이전 참조, B, 상·하위 계산 기록, 적용 조향, 처리 시간과 경고를 유지한다.
- 카메라 영상, 중복 EKF 위치, 중복 경로/제약 시각화, 별도 적용 명령 복제는 제외한다.
  하위 추적 기록에 실제 조향/명령이 포함되어 있다.
- decoded.pkl 같은 추가 비압축 사본은 자동 생성하지 않는다.
- 현재 두 주행을 변환해 보니 18.69 MB → 0.74 MB, 16.54 MB → 0.72 MB였다.
  같은 데이터 밀도라면 분당 약 1.5~1.8 MB이며 10회에 총 10~20분이면
  bag 약 15~35 MB 예상이다. 실제 시간·지도 복잡도·로그량에 따라 달라진다.
- 시작 시 1.5 GiB 이상 여유가 필요하다. 세션 512 MiB 도달 또는 여유 1 GiB 미만이면
  중단을 요청한다. 정지 확인/파일 마감 중 추가 기록은 조금 더 발생할 수 있다.
- 기존 주행 자료는 삭제하지 않는다. 다른 프로그램의 독립 로그는 관리하지 않는다.
