## 동작은 키네메틱 중심점 모델과 잘 맞음

SIH 원본 기준 지표:

| 항목 | 절댓값 중앙값 | 95백분위 | 최대 |
|---|---:|---:|---:|
| 진행 방향 − 차체 방향 | 0.685° | 9.425° | 10.467° |
| 출력 기준점의 횡속도 | 0.0334m/s | 0.537m/s | 0.599m/s |
| 수평 속도 | 3.207m/s | 3.287m/s | 3.307m/s |
| yaw rate | 1.384°/s | 22.065°/s | 24.267°/s |

남은 약10°를 이전과 같은 타이어 슬립으로 판단하면 안 된다.
회전 중 `차체 횡속도 / yaw_rate`를 맞추면 약1.396m다.
출력 기준점이 뒷차축보다1.4m 앞에 있다고 보고
`rear_vy = reported_body_vy - 1.4*yaw_rate`로 환산하면:

- 횡속도 잔차 절댓값 p95=0.00887m/s, 최대=0.00995m/s.
- 뒷차축 이동 방향−차체 방향 차이 절댓값 p95=0.205°, 최대=0.494°.

HIL 속도 양자화(0.01m/s)를 고려하면 무슬립 뒷차축 운동과 매우 잘 맞는다.
즉 출력이 뒷차축 중심 자체가 아니라 약1.4m 앞, 대칭 차량의 중심점에 해당하는
키네메틱 모델로 보인다. 약10°는 이 기준점이 회전할 때 생기는 기하학적 차이다.
타이어 슬립의 지속으로 해석하지 않는다.

## 기존 MPC 조향 응답은 이제 크게 어긋남

하위 시작 로그: actuator_model=1, delay=0.30s, tau=1.00s, N=30.
보드 파라미터 응답은 wheelbase2.8m, max steering0.35rad, SIH_T_TAU0.05s.

기존 응답을 명령 이력에서 재구성한 yaw-rate 오차 RMS는 약8.014°/s다.
다음 새 비교 모델은 전체0.174°/s, 앞 구간0.168°/s,
뒤 구간0.187°/s로 실제 회전 응답과 잘 맞았다.

```
normalized command → gain 0.35rad → first-order tau 0.05s
beta = atan(0.5*tan(delta))
yaw_rate = horizontal_speed/2.8 * cos(beta) * tan(delta)
```

순수 지연은 이 로그의 0.01초 탐색 해상도에서0초가 가장 잘 맞았다.
이는 물리 통신 지연이 정확히0이라는 뜻이 아니다.
자유 추정의 0.346 gain은 먼저 중심점 보정을 생략한 등가 모델에서 얻은 값이다.
최종 비교는 live parameter dump의0.35를 사용하고 중심점 기하학을 포함했다.
구간 분할은 같은 주행 내부 검증이며 독립적인 재주행 검증이 아니다.

기존0.3초/1초 값을 그대로 둬서는 새 차량을 제대로 예측하지 못한다.
또 현재 MPC는 위치를 전진 방향으로 이동시키므로, 중심점 출력을 뒷차축으로
변환하거나 제어 모델에 중심점 기하학을 포함해야 한다. 방향만 바꾸거나
합성속도를 전진속도로 바꾸는 것만으로 기준점 문제가 전부 해결되지는 않는다.
