apply/rollback은 현재 파일이 예상hash와 같을 때만 수행한다. 이후 추가 편집이 있으면
덮어쓰지 않고 중단한다. rollback은 이번 작업 전 바이트로 돌아가므로 기존 미커밋 변경 보존.
관련 프로세스가 있으면 거부하며 강제종료하지 않는다. Python 파일3개만 교체,빌드 불필요.
위 apply/rollback을 실제 운영에 실행하지 않았다. 사용자 지시를 기다린다.
