4. 왜 GPS 실패가 정지 후에도 남았는가
이번 기록에서 실패한 GPS 항목은 check_fail_max_horz_drift와
check_fail_max_horz_spd_err 두 개다. 다른 check_fail_*는 발생하지 않았다.
GPS 정지 검사 필터는 시정수 10초이며 이동 중 정지 오판 때문에 값이 누적됐다.
실제 정지 이후에도 속도 드리프트 실패가 약 19.81초, 위치 드리프트 실패가
약 23.69초 남았으며, 수평 추정은 약 24.69초 뒤 복구됐다.
따라서 이번 로그에서는 영구 미복구가 아니다.

주의: estimator_gps_status.checks_passed는 전 구간 true였다.
이 커밋에서는 초기 통과를 기억하는 래치로, 현재 검사 실패 여부를 의미하지 않는다.
현재 상태와 복구 판정에는 개별 check_fail_* 및 실제 융합/valid 플래그를 사용했다.
EKF2_GPS_CHECK=1023, EKF2_REQ_GPS_H=10, EKF2_REQ_HDRIFT=0.1,
EKF2_NOAID_TOUT=5000000us. GPS 재수용은 초기 건강 승인 래치가 이미 켜진 경우
최근 실패 후 max(1초, 건강시간/10) 조건을 적용하므로 매번 10초 대기를 요구하지 않는다.

6. 최소 수정안 — 아직 적용하지 않음
범위를 SYS_HITL==2 && SIH_VEHICLE_TYPE==4인 SIH Ackermann으로 제한한다.
기존 IMU 기반 정지 조건에 더해, 신선하고 유효한 SIH groundtruth 속도로 정지
허용 여부를 확인한다. 실제 속도가 남아 있으면 at_rest를 강제로 해제한다.
EKF 추정 속도, 스로틀 0, DISARM을 실제 정지의 대용으로 사용하지 않는다.

초기 제안값: 실제 수평 속도 >0.05m/s이면 정지 해제,
<0.02m/s가 1초 지속되고 기존 IMU 정지 조건도 만족할 때만 정지 허용.
0.02~0.05m/s는 히스테리시스로 처리하고 정지 진입 대기 중에는 at_rest=false.
truth timestamp age <=200ms, finite vx/vy와 v_xy_valid를 확인한다.
해당 SIH 모드에서 truth가 없거나 오래됐으면 정지로 확정하지 않는다.
이는 설계 제안이며 실제 커스텀 소스에서 필드/갱신 계약 확인 및 빌드 검증이 필요하다.

landed/ground_contact, 실제 하드웨어 rover 동작, GPS 검사 및 ARM 정책은 유지한다.
검증은 정속 직진, 입력 0 감속, 완전 정지, 재출발, truth 갱신 중단을 포함한다.
특히 감속 동안 두 at_rest가 false인지, 정지 후 true로 복귀하는지, GPS 검사
실패 및 수평 invalid가 재발하지 않는지 확인한다.
